# Хороший полицейский — бот для мессенджера MAX

Самостоятельный бот: сам собирает новости из официальных источников МВД,
сам отбирает истории о добрых поступках сотрудников, сам отправляет их
кураторам на модерацию и сам публикует одобренное в канал MAX.

Это **отдельный проект** от Telegram-версии (`kindpolicebot`): свой
токен, своя база, свой сервер. Боты не связаны и не мешают друг другу.

---

## Быстрый старт

```bash
pip install -r requirements.txt
```

```bash
cp .env.example .env
```

Заполните `.env` (как минимум `MAX_BOT_TOKEN`, `MAX_MODERATOR_CHAT_ID`,
`MAX_PUBLISH_CHAT_ID`, `MAX_ADMIN_IDS`, `AI_PROVIDER_API_KEY`), затем:

```bash
python main.py
```

Проверки без сети:

```bash
python -m tests.test_pipeline && python -m tests.test_max_flow
```

## Порядок подключения

1. **Токен.** Получите у `@MasterBot` в MAX (`/create`), положите в
   `MAX_BOT_TOKEN`.
2. **Запустите бота** и напишите ему `/whoami` — он ответит вашим
   идентификатором в MAX. Впишите его в `MAX_ADMIN_IDS` и перезапустите.
   Идентификаторы MAX не совпадают с телеграмными.
3. **Чат модераторов.** Создайте закрытый чат, добавьте туда бота и
   кураторов, отправьте `/chatid`. Полученное число — в
   `MAX_MODERATOR_CHAT_ID`.
4. **Канал публикации.** Добавьте бота администратором в канал и
   отправьте туда `/chatid`. При добавлении бот сам напишет id чата.
   Число — в `MAX_PUBLISH_CHAT_ID`.
5. **Проверьте:** `/diag` покажет, что настроено, а `/test_publish` —
   отправит в канал тестовый пост.
6. **Меню команд** задаётся вручную у `@MasterBot` (`/commands`) —
   через API это сделать нельзя. Список для копирования есть в шапке
   `max_bot.py`.

## Чем версия для MAX отличается от Telegram

Возможности Bot API MAX уже, поэтому часть интерфейса устроена иначе.
Всё перечисленное проверено на живом токене — документация местами
отстаёт от действительности.

| Что | Telegram | MAX |
|---|---|---|
| Постоянная клавиатура снизу | есть | **нет** — меню открывается сообщением с кнопками по `/menu` и кнопкой «⬅️ Меню» |
| Авторизация | `/bot<токен>/метод` | заголовок `Authorization: <токен>`, **без** `Bearer` |
| Адрес API | api.telegram.org | `botapi.max.ru` (указанный в части документации `platform-api2.max.ru` не отвечает) |
| Получатель | в теле запроса | в query: `/messages?chat_id=…` или `?user_id=…` |
| Кнопки | `reply_markup` | вложение `inline_keyboard` в `attachments` |
| Список чатов бота | доступен | `GET /chats` боту **недоступен** (404) — `chat_id` узнаём из событий |
| Меню команд | `setMyCommands` | только вручную у `@MasterBot`: `PATCH /me` отвечает 404 |
| Лимит текста | 4096 | 4000 |
| Библиотека | aiogram | своя обёртка `maxapi.py` — аналога aiogram для MAX нет |

Логика отбора новостей, рерайта, рисования карточек, ИИ-помощника и
справочника — та же, что в Telegram-версии.

Меню открывается по `/start` или `/menu`:

```
🆘 Что делать, если…    ☎️ Телефоны
💬 Задать вопрос        🏛 Источники МВД
📰 Хорошие новости      🎓 Учёба в МВД
📍 Мой регион           ℹ️ О проекте
```

| Раздел | Что внутри |
|---|---|
| 🆘 **Что делать, если…** | 10 пошаговых памяток: пропал человек, кража, мошенники, ДТП, как подать заявление, отказ принять заявление, права при задержании, потерялся ребёнок, угрозы и насилие, нашли чужую вещь |

| 💬 **Задать вопрос** | ИИ-помощник отвечает простым языком |

| 🎓 **Учёба в МВД** | как поступить + список вузов |

`/news`, `/education`, `/region`, `/about`, `/whoami`, `/help`.
Можно просто написать вопрос обычными словами.

## Служебная часть

Служебные команды видны **только** пользователям с ролью в базе:
обычному пользователю бот отвечает отказом. Карточки на модерацию
уходят в закрытый чат `MAX_MODERATOR_CHAT_ID`, где обычных
пользователей нет.

### Модератор
`/fetch` · `/pending` · `/stats` · `/audience` · `/schedule_status` · `/chatid`

### Администратор
`/diag` · `/schedule_on` · `/schedule_off` · `/set_interval N` ·
`/add_moderator ID` · `/remove_moderator ID` · `/list_moderators` ·
`/clear` → `/clear_confirm` · `/cleanup_images` · `/assistant_log` ·
`/broadcast текст` · `/add_resource` · `/list_resources` ·
`/remove_resource` · `/reseed` · `/test_publish`

На карточке новости три кнопки: «✅ Опубликовать», «❌ Отклонить»,
«🖼 Другая картинка». Нажатие от постороннего игнорируется, а повторное
нажатие не публикует пост второй раз — статус меняется одним
атомарным запросом к базе.

## Деплой

В проекте есть `Dockerfile`: на хостинге включите «Использовать
собственный Dockerfile». Он ставит шрифт DejaVu — без него Pillow
нарисует на карточках пустые квадраты вместо кириллицы.

Точка входа — `main.py`. Нужен Python 3.10+.

**Не запускайте два экземпляра с одним токеном**: оба будут забирать
события длинным опросом, и часть сообщений потеряется.

**База** лежит в `storage/bot.db`. Если хостинг пересоздаёт контейнер
при деплое, база обнулится: пропадут роли, история и пользователи.
Администраторы и справочник восстановятся сами, остальное — нет.
Для постоянного хранения смонтируйте диск и укажите путь в `DB_PATH`.

## Структура

```
main.py                  точка входа
max_bot.py               бот: меню, разделы, модерация, админка
maxapi.py                клиент Bot API MAX (своя обёртка)
app.py                   веб-панель модерации (необязательна)
config.py                настройки из .env
content/                 памятки, телефоны, справочник источников
pipeline/                отбор, рерайт, карточки, ИИ-помощник
sources/                 RSS и публичные Telegram-каналы как источники
storage/                 модели и SQLite
tests/
  test_pipeline.py       логика без сети (141 проверка)
  test_max_flow.py       сценарии бота через события MAX (100 проверок)
```

Telegram-каналы остаются **источниками новостей** и в этой версии:
бот читает их публичные страницы, токен Telegram для этого не нужен.
